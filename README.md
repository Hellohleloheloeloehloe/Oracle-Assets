# Oracle-Assets

Public images used by the Oracle script, downloaded and cached in the executor workspace at runtime.

- `logo.png` - Oracle wordmark, white on transparent (348x48, box-downscaled so it stays sharp at 13-17px). Tinted to the accent color in-game.
- `fonts/lucide.ttf` - Lucide icon font (ligatures: set a TextLabel's text to an icon name). From notpoiu/lucide-roblox-direct @ d64d9e6; Lucide is ISC licensed, see `fonts/LICENSE-lucide.txt`.
